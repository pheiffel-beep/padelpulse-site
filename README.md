# padelpulse.app

Site vitrine de l'application **PadelPulse**, le carnet de bord du joueur de padel.

- `index.html` — page d'accueil (français)
- `nl.html` — page d'accueil (néerlandais)
- `mentions-legales.html` / `juridisch.html` — mentions légales
- `confidentialite.html` / `privacy.html` — politique de confidentialité
- `img/` — captures de l'application
- `fonts/` — Manrope et Barlow Condensed (licence OFL, voir `fonts/`)
